# auditcell

Audit timestamps and cell durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/auditcell/

## Install / run

```bash
git clone https://github.com/theworker02/auditcell.git
cd auditcell
node src/cli.js
node --test
```
